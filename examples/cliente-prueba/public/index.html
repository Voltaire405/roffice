Cliente de prueba Roffice

Simula un tenant: lista el prefijo sandbox, abre el editor en una pestaña y registra cada guardado que Roffice solicita.

Patrones del menú «Insertar patrón» (solo docx en edición)

patterns: string[]. patternGroups: árbol de hojas { label, pattern } y grupos { label, children }, hasta 4 niveles. Se envían tal cual en cada apertura; vacía el campo para no enviar patrones.

Documentos relacionados (PDF, cualquier modo)

Una línea por documento: Nombre - URL. Roffice descarga la URL desde el servidor, no desde tu navegador: debe responder sin cookies y seguir viva mientras el editor esté abierto. Vacío = sin documentos relacionados. En el editor se abren desde la pestaña «Extensiones».
